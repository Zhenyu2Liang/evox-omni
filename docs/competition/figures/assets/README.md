# 插图素材

- `wechat.svg`：[Simple Icons 的 WeChat 标识](https://github.com/simple-icons/simple-icons/blob/develop/icons/wechat.svg)。许可为 [CC0 1.0](LICENSE-simple-icons.md)。
- 其余模块插画由 `scripts/generate-competition-figures.mjs` 中的 SVG 绘图代码生成，配色与模块职责一致。

图中文字优先使用 [Noto Sans SC](https://fonts.google.com/noto/specimen/Noto+Sans+SC)，缺少时使用微软雅黑。模块标题用 600 字重，PPT 业务名称用 500 字重，说明用 400 字重。同一张图的字号统一。
