# 定时任务与提醒

定时意图现在有实际的到期处理入口。`/schedules` 显示当前可信会话的任务、到期状态和持久化提醒通知；点击“检查到期任务”执行一次服务器检查。后台也可以执行 `pnpm scheduler:tick`。两种入口都使用同一分发服务。

## 到期行为

- `REMINDER` 到期后写入 `ScheduledNotification`，并将任务改为 `DONE`。通知和必需审计在同一事务提交；审计失败时不留下已经送达的记录，下一次检查可以安全重试。
- `TRANSFER` 和 `PAYMENT` 到期后保存一个完整的付款工作流，再通过现有 Security Gateway 执行。当前 `PAYMENT` 也使用 Demo 转账通道，不表示已接入商户支付。
- 付款会重新评估收款人、金额、余额、累计风险和权限。需要确认或 MFA 时停在 `AWAITING_CONFIRMATION`，由用户前往 AI 助手完成决定。记录中的 `requiresConfirmation` 不能免除当前权限检查。
- 重复检查会复用已保存的工作流和原待授权操作。已等待确认、MFA 或人工处理的任务不会被后台自动继续。确认完成后的任务状态来自已提交的工作流事实。
- 等待人工决定的付款不占本轮分发容量，后续新到期提醒和付款可以继续产生办理入口。
- 尚未派发的意图可以取消；已派发付款通过所属计划的取消入口处理，撤销未执行授权并保留已提交事实。SDK 拒绝把仍有活动工作流的意图直接标成已取消。
- 执行参数只支持明确收款人和合法金额。任意工具名、可执行代码、验证码以及不支持的命令会在创建付款工作流之前拒绝。

定时任务遵循 `SCHEDULED → DISPATCHING → AWAITING_CONFIRMATION → DONE` 的常见路径；提醒直接从 `SCHEDULED` 进入 `DONE`。明确失败显示 `FAILED`，取消显示 `CANCELLED`。临时基础设施故障在尚未创建工作流时保留 `SCHEDULED` 并记录错误，允许后续检查重试；已启动工作流的金融事实和授权状态继续由原工作流处理。

## 时钟与身份

服务器 HTTP 入口使用真实系统时间。浏览器不能提供 `now`、用户 ID 或会话 ID；Cookie 身份和任务所属会话由服务端验证。一个会话不能分发或读取另一个会话的定时意图。

比赛演示需要快进到未来日期时，可以从可信服务器命令行显式指定时间：

```sh
pnpm scheduler:tick --now '2099-11-20T09:00:00+08:00'
```

CLI 每次执行一轮有界检查，不持续驻留。部署时可以由进程管理器或定时调度服务反复调用该命令。它只遍历已经保存来源会话的任务，也不会替用户确认付款。预置演示任务由已认证的页面检查建立来源会话绑定。

工作流调度时间和确认/MFA 有效期各自遵循相应时钟：演示日期快进可以触发到期意图，但不能伪造新授权或延长验证有效期。

## API 与实现

- `GET /api/schedules`：读取当前会话的任务及最近提醒通知。
- `POST /api/schedules/tick`：请求体为 `{}`，执行一次真实时间检查，返回各任务的分发状态。
- `agent/scheduled-command.ts`：纯命令编译，规范化金额并拒绝不支持的可执行载荷。
- `agent/scheduled-dispatcher.ts`：身份范围、原子分发、提醒交付、权限入口及工作流状态同步。
- `ScheduledTask.dispatchTaskId`：定时意图和唯一持久化工作流的关联；`ScheduledNotification.scheduledTaskId` 唯一约束提供提醒去重。

当前 schema 通过 `pnpm db:generate`、`pnpm db:push --skip-generate` 应用。项目不提供旧 schema 转换；重新初始化演示数据使用 `pnpm db:reset`。

## 比赛展示边界

生日采购仍是模拟：系统可以预留预算意图、保存未来提醒并在到期时送达通知，不会真正购买鲜花或蛋糕。`reserve_budget` 不冻结银行账户资金，定时付款也不提前扣款。真实资金冻结、商户采购接口和真实银行员工身份不在此实现范围内。

`tests/app/scheduled-dispatch-http.test.ts` 覆盖并发提醒一次交付、审计回滚后重试、到期付款重新要求 MFA、重复检查不重复扣款、跨会话拒绝、旧记录归属竞争时不泄漏新工作流、待确认任务不阻塞后续提醒、分发后取消保护及非法载荷拒绝；纯编译用例位于 `tests/unit/planner/scheduled-command.test.ts`。
