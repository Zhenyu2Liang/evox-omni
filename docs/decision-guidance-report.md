## 两项修复

1. **多笔转账升级 MFA 后摘要不一致**：安全网关在同一授权事务内更新 RED 风险列与完整 `summaryJson`；确认响应的 MFA 事件携带金额、收款人与风险摘要。前端按操作 ID 替换旧确认卡，决定一笔操作不会清除另一笔待处理决定。SSR 与待处理操作接口使用当前数据库权限规范化摘要，兼容历史黄色摘要。历史终态卡不重新开放执行。
2. **固定提示丢失必要澄清信息**：增加封闭的 guidance 原因码和字段词表，服务端渲染能力限制、歧义选择和缺信息模板。支持受校验字段及 JSON 围栏，不接受任意说明文字、金额或执行状态。明确匹配现有产品名/代码及单笔有效数值金额时，不把这些字段再作为缺失信息询问。无有效 guidance 时只说明静态能力边界，不猜测用户缺少哪些已提供信息。真实结果与确认状态仍优先于澄清。

mock 的银行运行路径使用同一协议；原纯响应器保持兼容。补充金额后保留先前指定的产品，不用默认产品替代。
