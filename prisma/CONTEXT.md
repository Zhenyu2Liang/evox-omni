# Prisma Data Layer — Context

## Intent

Owns the **SQLite data contract** for the AI Banking Agent demo: the Prisma schema
(`schema.prisma`), the database seed data (`seed.ts`, owned by a sibling agent) and migrations.
All banking data is simulated — this is a demo sandbox, no real bank/money.

## Files

- `schema.prisma` — the Prisma schema (SQLite). Defines every table, relation and index.
- `seed.ts` — demo seed data (李明, contacts 张伟/王芳/妈妈/李华, transactions incl. the anomaly, cards,
  subscriptions, investment products). **Owned by a sibling agent** — do not edit here.
- `migrations/` — Prisma migration history (generated by `prisma migrate`; not run in this worktree).

## API Surface

Prisma models (see `schema.prisma` for exact fields):

- `User` — demo user; roots to accounts, cards, contacts, subscriptions, holdings, budgets, sessions,
  scheduledTasks, auditLogs, securityEvents.
- `Account` / `Transaction` — checking/savings balances and ledger (signed `amount`, anomaly flags).
- `Contact`, `Card` + `CardLimit`, `Subscription`, `Budget`.
- `InvestmentProduct` / `InvestmentHolding` — products and user holdings.
- `AgentTask` / `AgentTaskNode` — planner task DAG (nodes store `args`/`output`/`dependencies` as JSON text).
- `ScheduledTask` — future reminders/payments/transfers.
- `AuditLog` / `SecurityEvent` — append-only audit + security records.
- `AgentSession` — per-session serialized agent state (`stateJson`).
- `PendingAction` / `MfaChallenge` — two-phase YELLOW/RED confirmation + mock MFA.

## Constraints

- **SQLite**: no native enums — every enum-like/status field is a `String` (allowed values documented in
  the header comment of `schema.prisma`). JSON-ish payloads are JSON text in `String` columns.
- **Money** is `Float` in CNY; callers format via `lib/money` helpers. Amounts are signed
  (negative = expense, positive = income).
- IDs use `@default(cuid())`; timestamps use `@default(now())` / `@updatedAt`.
- Enums, status values and cross-module types must stay consistent with the frozen contracts in
  `lib/contracts/` (root-owned) — never fork a type here, only persist its string form.
- Do **not** run Prisma commands from this node in isolation; `npm install` / `prisma generate` /
  `db push` / `db:seed` are documented at the repo root.

## Notes for Agents

- The **Prisma client singleton and typed repositories live in `lib/db`** (`lib/db/client.ts`,
  `lib/db/repositories/*`) — those own all data access. This directory only owns the schema + seed.
- Keep `schema.prisma` in sync with `lib/contracts/` (risk levels, audit status, permission tiers);
  field names here are the source of truth for `lib/db` repositories.
- File-size rule: keep the schema readable; split only if it exceeds ~1000 lines.
