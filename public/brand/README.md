# 万象柜坊品牌资源

`omni-x.svg` 从用户提供的 EvoX“透明底.svg”中提取 X 标志。
保留原始 18 条路径、透明背景和两种填色，不包含 E、V、O 字形。
只调整画布范围；原始文件保持不变。

品牌色为朱红 `#C8383C` 与炭灰 `#373435`。
界面使用深暖灰文字 `#3E3430`、暖褐灰辅助文字 `#786B63` 和暖白背景 `#FBF8F5`。
普通交互使用暖褐色 `#77574B`，信息背景使用浅暖粉 `#F8EEEA`。
边框使用暖灰 `#E8E0D9`，次要按钮与悬停背景使用米灰 `#F3EEE8`。
朱红用于 Logo、主要按钮、选中标记与交互强调。
错误色为深红 `#B42318`；成功绿色、警告琥珀色独立保留。
分类图表使用独立的柔和配色，不借用成功或失败颜色表示类别。
图表以蓝绿 `#6F9E9A`、杏橙、灰紫和鼠尾草绿搭配，保留冷暖层次。环图与柱图的分类颜色一致。
趋势线使用蓝绿 `#5E8988` 与浅色面积填充，与暖白页面背景区分。账单金额使用深暖灰。
朱红集中于主按钮、导航标记和页面标题细线；主按钮悬停使用深朱红 `#A62F34`。
信用卡、借记卡和虚拟卡的卡面分别使用浅豆沙、雾蓝和浅鼠尾草绿；失效卡面使用暖灰。
资产、订阅、联系人、理财和助手入口局部使用蓝绿、雾蓝、灰紫与杏色辅助色。
这些辅助色使用浅色背景和深色文字，金额保留深暖灰；颜色不代替状态标签。
助手头像使用暖米色背景。Logo 保留原色，成功、警告和风险状态色保留原语义。
全局颜色在 `app/globals.css`，图表对应色在 `components/charts/chartTheme.tsx`。

左侧导航、手机导航和对话欢迎区复用本资源。
`app/icon.svg` 使用相同路径，画布调整为正方形，用于浏览器图标。
产品名称为“万象柜坊”，英文名为“EvoX Omni”。
标语为“一坊通万象，一语办万事。”。
“柜坊”取意于古代柜坊；“万象”对应转账、账单、理财、卡片管理与跨场景任务。
