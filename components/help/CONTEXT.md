# 首次使用引导与使用帮助

`AssistantHelpProvider` 由 `AppShell` 挂载。
仅首次进入 `/agent` 时自动打开原生对话框。
桌面标题栏和手机标题栏各有一个帮助入口，仅显示当前尺寸的入口。
引导提供功能说明、操作步骤、确认规则和模拟业务边界。
正文和边框保持中性色，步骤卡和示例采用蓝绿、雾蓝、灰紫和杏色辅助色。
朱红只强调品牌署名与主要操作，安全分级保留原状态色。
所有界面文字使用 `lib/i18n/messages/app.*.json` 中的 `help.*` 键。

关闭按钮、Escape、背景或“开始使用”都会记住关闭状态。
`guide-preference.ts` 优先读取本地存储，并以 Cookie 作为后备。
偏好只在当前浏览器和同源地址生效，不写入共享会话或银行数据库。
清除浏览器数据或更换地址后会重新显示。
浏览器同时禁用两种存储时，帮助仍能手动打开和关闭，刷新后可能再次显示。

示例通过 `Composer` 注册的回调填入输入框，不发送对话请求。
输入框有草稿、正在恢复或请求中、存在待确认或待核对操作时，示例不可用。
关闭帮助不改变草稿、会话、授权或业务状态。
原生模态对话框隔离背景交互，键盘焦点在可用按钮间循环。
手机和短窗口内只有内容区滚动，标题、关闭按钮和底部按钮保持可见。
